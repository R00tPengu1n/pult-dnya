---
name: study-sync
description: По запросу «обнови учёбу» переносит прогресс курса с учебной платформы в блок «Учёба» на «Пульте дня».
---

Обнови блок «Учёба» на дашборде «Пульт дня» (<ARTIFACT_URL>) по прогрессу курса на учебной платформе (Open edX). Слаг базы для всех вызовов db_*: `<ARTIFACT_SLUG>`. Курс: `<COURSE_ID>`.

1. Открой во встроенном браузере `<LEARNING_URL>/course/<COURSE_ID>/home`. Если открылась страница входа, попроси пользователя войти самому и дождись ответа. Логин и пароль не вводи.
2. На странице курса выполни GET `<LMS_URL>/api/course_home/v1/progress/<id курса, через encodeURIComponent>` с `credentials: "include"`. Только чтение: никаких POST и отметок на платформе.
3. Из `section_scores[].subsections[]` возьми элементы, чьё название начинается с «Модуль N.». Прогресс = round(num_points_earned / num_points_possible * 100).
4. Для каждого модуля с документом `study/sf-mN` в базе: прочитай его, затем db_write update с ifVersion: `progress`, и если прогресс 100, то `done: true`, `doneAt: сейчас`. Поля `title` и `deadline` не трогай: сроки ставит пользователь. Модули, которые пользователь отметил сделанными вручную, обратно не снимай.
5. Новых модулей не добавляй. Если на платформе появился модуль, которого нет в базе, назови его и спроси.
6. Одной-двумя строками ответь, что изменилось.

Поле `due` в API курса одинаковое у всех модулей и означает общий срок курса, а не сроки модулей: его не используй.
